# 🏎️ F1 2026 Championship Prediction

An end-to-end machine learning system that estimates **Formula 1 2026 World Drivers' Championship probabilities** using historical race data, driver and constructor performance features, Random Forest regression, Monte Carlo simulation, and probability calibration.

The system predicts individual race finishing positions and uses thousands of simulated championship outcomes to estimate each driver's probability of winning the 2026 Drivers' Championship.

## 📌 Project Overview

Predicting an F1 championship is different from predicting a single race.

Instead of directly predicting the championship winner, this project follows a race-by-race approach:

```text
Historical F1 Data
        ↓
Data Cleaning
        ↓
Feature Engineering
        ↓
Random Forest Regression
        ↓
Race Finishing Position Prediction
        ↓
Monte Carlo Championship Simulation
        ↓
Historical Backtesting
        ↓
Probability Calibration
        ↓
2026 Championship Probabilities
